# Progress

## Тестовое задание

## Описание
Прототип блока **Progress** для использования в мобильных web-приложениях.  
Блок отображает прогресс в виде круговой дуги и поддерживает три состояния:  
`Normal`, `Animated`, `Hidden`.

## Стек
- HTML  
- CSS  
- JavaScript (без библиотек)

## Структура проекта
- `index.html` — разметка и элементы управления  
- `style.css` — стили и адаптация под портрет/ландшафт  
- `script.js` — логика компонента и его API  
- `README.md` — описание проекта

## API
- `setValue(number)` — установить значение прогресса  
- `setAnimated(boolean)` — включить/выключить анимацию  
- `setHidden(boolean)` — скрыть/показать компонент
